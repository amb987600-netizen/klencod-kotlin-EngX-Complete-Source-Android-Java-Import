# ما تم اختباره في النسخة المحدّثة

نجح **49 اختبارًا محليًا** عبر Vitest، و**18 اختبارًا كما أحصاها Node Test للخادم**. نجح فحص TypeScript وتجميع نسخة الويب بواسطة Vite. جرى تحديث ونسخ أصول Android بواسطة Capacitor، ونسخ أصول iOS. هذا لا يعني تجميع تطبيق أصلي أو اعتماده على هاتف.

## الأقسام والصور

تغطي الاختبارات عزل السجلات والبحث والتصدير والمحادثة بين الأقسام، وبقاء البيانات القديمة في قسم الأجهزة الطبية، وحماية فتح جهاز تابع لقسم آخر. في المتصفح أضيف موبايل تجريبي، ثم أُنشئ أمر عطل برفع صورتين معًا. حُفظتا وأعيد فتحهما مع المعاينة. الانتقال لقسم البيع لم يعرض الموبايل أو أوامره، وظهرت المنتجات والمستندات بدل شاشات الصيانة غير المناسبة.

## الإشعارات والودجت

تغطي الاختبارات فئات الصيانة والمعايرة والمخزون والتكليفات والاعتمادات والرسائل، العزل والخصوصية والتعامل مع السجلات المحذوفة والمعايرات القديمة. جُرّب حفظ فئة التنبيه وفتح أمر الشغل بصوره من تنبيه التكليف. اختبارات الودجت تتحقق من العدادات والروابط والمقاسات والموارد المتوافقة ومعرّف الحزمة؛ لا تختبر مشغّل هاتف فعليًا.

## المالك والمساعدون

اختبارات HTTP تتحقق من رمز إعداد عشوائي فعلي صادر عن أداة الخادم، ورفض إعادة استعماله، وفصل توكن المالك عن توكن المستخدم العادي، وثلاثة مقاعد للمساعدين، ومنع الوصول عند خلو المنح، وعزل مساحة العمل والقسم ونوع السجل. تشمل منع كشف عضويات خارج النطاق، ومنع المساعد من إدارة المساعدين أو تعليق مالك مساحة، وتعليق الجلسة واستعادة كلمة المالك وإبطال التوكن القديم، وسجل القراءة والتغييرات دون كلمات المرور.

جُرّبت الواجهة على قاعدة اختبار منفصلة: إعداد مالك أولي من شاشة التطبيق، دخول اللوحة، ثم دخول مساعد دون منح. ظهر له عرض فارغ ولم تظهر إدارة المساعدين أو التدقيق. بيانات هذا الاختبار وكلمات مروره ورموز إعداده غير مضمنة في الحزمة، ولا توجد حسابات مالك جاهزة.

## وظائف سابقة ما زالت مختبرة

الحفظ دون اتصال، الصلاحيات المحلية، إغلاق أوامر العمل، الخصم الذري للمخزون ومنع تكراره، استيراد Excel والتراجع، تشفير النسخ وكشف العبث والاستعادة، ثبات أكواد السجلات، أدوات المساعد المسموح بها، الدعوات والإيقاف، وعزل الملفات والمحادثات على الخادم.

## ما لم يُختبر

لم تُبنَ نسخة APK أو IPA موقعة، ولم يُختبر هاتف فعلي أو إشعارات النظام أو الودجت أو الطباعة الأصلية. لا يوجد Xcode في بيئة Linux هذه. استخدم مسار GitHub Actions المرفق أو Android Studio وSDK وJDK المناسبين لبناء أندرويد واختباره.

لم يُنزّل نموذج Gemma الكبير، ولم تُختبر إجابات فعلية منه أو مزود API مدفوع. لم يُنشر خادم إنتاج ولم يُجرَ اختبار اختراق أو اعتماد طبي/تنظيمي؛ هذه اختبارات تطوير وليست بديلًا عن اختبار قبول المؤسسة وإعدادات النشر الآمنة.
