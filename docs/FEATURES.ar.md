# وظائف EngX وحدودها

## الموجود في المشروع

| الوظيفة | التنفيذ |
|---|---|
| الأقسام | سبعة أقسام بمدخل وتصفح مستقل، وتغيير من الملف الشخصي أو القائمة العلوية؛ السجلات والبحث والمخزون والمحادثة المعروضة تخص القسم. |
| الأجهزة | إضافة وتعديل وحذف ناعم، كود فريد داخل القسم، بحث وحالات وملف جهاز؛ البيانات غير الأساسية اختيارية. |
| إدخال البلاغ السريع | الجهاز والوصف فقط، مسودة تلقائية، تاريخ وساعة محليان تلقائيان، وتعديل وقت الاكتشاف بسجل أثر. |
| الصيانة | أربع خطوات، قطع وصور وPDF متعددة بمعاينة وحذف وإعادة محاولة، مربعات تحقق، نتائج اختبار، طلب اعتماد ثم اعتماد المالك/المدير. المغلق لا يُعدّل ولا يُحذف. |
| المعايرة وQR | سجل معايرة يدوي، رمز جهاز وتصدير ملصق؛ قراءة من صورة على الهاتف أو إدخال الكود محليًا. |
| المخزون والوقائية | صرف مرتبط بأمر مع خصم الكمية معًا، وحد إعادة طلب؛ الفترات والمواعيد يحددها المستخدم دون قيم طبية مفترضة. |
| التقويم والتذكيرات | يوم/أسبوع/شهر، وأحداث وتذكيرات محلية بإذن النظام؛ لا ضمان بعد إغلاق صفحة الويب. |
| التقارير | أرقام فعلية، أعطال شهرية ومتكررة، جاهزية حسب الحالة المسجلة لا اعتماد سريري، متوسط وقت إصلاح وتكلفة وأكثر القطع استخدامًا، CSV وطباعة PDF. |
| Excel | `.xlsx` و`.xls` و`.csv`، الورقة الأولى، معاينة وربط وتحقق، دفعة كاملة أو لا شيء؛ تراجع آمن عن غير المعدل وغير المرتبط. |
| سجل النشاط | تغييرات باسم العضو وقيم قبل/بعد، وتنقل وبحث واستيراد وتصدير ونسخ وحساب وفريق؛ لا واجهة لتعديل السجل. |
| الحفظ دون إنترنت | Dexie/IndexedDB، وقائمة انتظار للمزامنة. |
| النسخ المشفر | AES-256-GCM وPBKDF2، يشمل السجل والمرفقات وذاكرة المحادثة المحفوظة؛ اختبار استعادة في قاعدة مؤقتة دون لمس الأصل. |
| المزامنة والفريق | خادم Express/SQLite اختياري، أدوار ودعوات وإيقاف ونقل ملكية، مع فحص الصلاحيات على الخادم. |
| المحادثة | مجموعة للقسم داخل المساحة؛ تحديث تلقائي عند فتحها مع الإنترنت والسحابة، وقراءة ما حُفظ فقط دون اتصال. رقم داخلي فريد للحساب بدل الموبايل، وملفات باختيار المستخدم. |
| Android وiPhone | مشروعَا Capacitor أصليان، مشاركة ملفات وطباعة، ومشروعا Widget/AppWidget وWidgetKit. لا APK/IPA موقّع في الحزمة. |
| Widgets | ودجت أندرويد تفاعلية: أعداد الأوامر والوقائية والمعايرة والمخزون والاعتمادات، ثلاثة عناصر أولوية وروابط مباشرة، وأزرار أمر جديد/QR/الإشعارات. الأسماء مخفية افتراضياً؛ لقطة محلية وليست مزامنة خلفية. ودجت iOS الأساسية محفوظة. |
| لوحة المالك | حساب منفصل للسجلات التشغيلية المتزامنة والمستخدمين والتدقيق، وثلاثة مساعدين بمنح دقيقة مفروضة على الخادم ورموز إعداد واستعادة عشوائية. |
| مركز الإشعارات | صيانة ومعايرة قريبة ومتأخرة، مخزون، اعتمادات، تكليفات، ورسائل غير مقروءة؛ تحكم في الفئات وطلب إذن صريح، مع نص نظام عام وحماية التفاصيل. |

## إعدادات وحدود مهمة

- لتشغيل التواصل بين الهواتف يجب نشر الخادم عبر HTTPS وإعداد الحسابات والعنوان. لا توجد خدمة سحابية منشورة أو حسابات حقيقية داخل الحزمة.
- المحادثة ليست نسخة من واتساب: لا مكالمات أو SMS أو رسائل خاصة فردية أو إشعارات دفع، ولا تشفير طرف لطرف. الملفات لا تُنزّل تلقائيًا.
- لا تُحدّث الودجت قاعدة البيانات وهي مغلقة. النظام قد يعيد عرض آخر ملخص؛ تحديثها يتبع فتح التطبيق وتغيير بياناته. iPhone يحتاج توقيعًا وApp Groups مطابقين.
- تمت مراجعة ملفات المنصتين ومزامنتها، لكن بناء Xcode/توقيع Apple واختبار هواتف فعلية غير متاحين في بيئة Linux هذه. تعذر تجميع أندرويد أصليًا بالأدوات الموجودة؛ لا تدّعي الحزمة اختبار جهاز فعلي.
- Google يعمل كتسجيل دخول للويب عند إعداد Client ID. النسختان الأصليتان تستخدمان البريد/كلمة المرور حاليًا؛ تسجيل Google الأصلي داخل WebView غير جاهز. لا Drive/Gmail/Contacts أو ربط مباشر بـ Sheets.
- البيانات المحلية غير مشفرة على مستوى التطبيق، بما فيها المحادثة التي حُفظت. النسخ الاحتياطية المشفرة منفصلة ويجب حفظها خارج الهاتف. فقدان كلمة مرور النسخة لا يمكن إصلاحه من الحساب.
- التعارض يُرفض للمراجعة، ولا يُدمج صامتًا. المرفقات مضمنة في طلبات المزامنة، لا رفع خلفي مستقل للملفات الكبيرة.
- إيقاف عضو بلا إنترنت لا يمكن أن يصل فورًا. تُحذف نسخة مساحة العمل وذاكرة المحادثة عند أول رد بإيقاف الوصول.
- الإنجليزية جزئية للعناوين الرئيسية. الأقسام السبعة مفعّلة؛ قسم البيع يعرض المنتجات والمستندات بدل الصيانة، وحقول الجهاز تناسب النشاط. المساعد يدعم أوامر محددة وذكاءً محليًا اختياريًا وAPI خاصًا اختياريًا؛ لا قراءة PDF تلقائية.
- لا بيانات مرضى في أي ملف أو رسالة. وجود سجل نشاط أو أمر مغلق لا يساوي سجلًا جنائيًا مقاومًا لكل عبث ولا شهادة سلامة أو اعتماد طبي.

## الإضافات الأخيرة

- أكواد ثابتة لكل سجل من معرفه الكامل، وحماية التغيير والتكرار على الخادم، مع عمود ترتيب قابل للعكس وبحث شامل.
- أوامر بيع وشراء داخلية مرقمة؛ ليست منظومة ضريبية أو محاسبة معتمدة ولا عملية دفع.
- شات أوامر خاص: إضافة جهاز، مسودة صيانة، بحث ولقطة تقرير؛ كل كتابة بمعاينة وتأكيد وصلاحيات. الأفعال الخطرة خارج أدوات المساعد.
- LiteRT-LM أصلي اختياري؛ نموذج Gemma 4 E2B نحو 2.58 GB غير مضمن. دمج المصدر لم يُختبر على هاتف حقيقي، وSwift Early Preview. حد iPhone أصبح iOS 15. المحلي غير مفعّل في الويب.
- API OpenAI-compatible اختياري، برسوم مزوده، ومفاتيح الهاتف في مخزن النظام، ومفتاح الويب مؤقت في الذاكرة. لا إرسال سياق تلقائي ولا fallback.
